# Course Pacer docs

The root `README.md` and `CLAUDE.md` are the entry points. This folder holds the rules, the decision records and the ideas not yet approved.

## Group and class organisation

- [GROUP_SETTINGS_BRIEF.md](GROUP_SETTINGS_BRIEF.md): group calendar/skip overrides, shared optional books, Collections, sorting and schema 11 (3.10.0).

## Rules and reference

- [PACER_ACCENT_CONTRAST.md](PACER_ACCENT_CONTRAST.md): measured contrast pairs for all four Bone/Saffron sets (3.8.0, D13). The shared suite guide remains on the previous palette.
- [BRIEF.md](BRIEF.md): the original port brief and the feature-parity checklist.
- [EDUSUITE_STYLE_GUIDE.md](EDUSUITE_STYLE_GUIDE.md): the shared EduSuite look. A copy of the canonical guide.
- [PACER_DESIGN.md](PACER_DESIGN.md): Course Pacer's own design language and its departures from the shared guide (approved redesign, built in 3.1.0 to 3.6.0; tokens landed in 3.1.0, navigation in 3.2.0, large text and the tablet layout in 3.6.0; Stats and Plan refinements in 3.9.0).
- [../PRODUCT.md](../PRODUCT.md): the product record (users, purpose, constraints, principles).

## Decision records

Each one records why a feature was built. The code and `CLAUDE.md` describe the current app.

- [YEARS_BRIEF.md](YEARS_BRIEF.md): school years, classes and groups (1.3.0).
- [LESSON_PAGES_BRIEF.md](LESSON_PAGES_BRIEF.md): recording the pages a lesson actually covered (1.5.0; date-specific menu actions in 3.6.1).
- [SIGNING_BRIEF.md](SIGNING_BRIEF.md): the permanent release signing key (built in 1.5.3; secrets limited to `main` since 1.7.3).
- [BACKUP_BRIEF.md](BACKUP_BRIEF.md): export and import of school years (1.6.0).
- [EXTRA_LESSONS_BRIEF.md](EXTRA_LESSONS_BRIEF.md): date-pinned core-book extra lessons, editing, re-pacing and schema 10 (3.7.0).
- [CUSTOM_PLANS_BRIEF.md](CUSTOM_PLANS_BRIEF.md): custom plans, a lead book and pace warnings (built in 2.6.0 to 2.9.0; menu and Undo fixes in 3.6.1).
- [CATCH_UP_REPACE_BRIEF.md](CATCH_UP_REPACE_BRIEF.md): preserving the chosen catch-up pace when re-pacing and adjusting it directly (3.6.2, schema 9).
- [SUPPLEMENTARY_BOOKS_BRIEF.md](SUPPLEMENTARY_BOOKS_BRIEF.md): supplementary books placed by hand in chosen lessons (2.10.0).
- [superpowers/](superpowers/): brainstorming specs and plans for Course Pacer only.
