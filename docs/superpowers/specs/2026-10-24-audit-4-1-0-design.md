# 4.1.0 audit: decomposition and design

Source: the owner's personal audit of 4.1.0 (ten numbered areas). This spec turns it into five deliverables (A to E), each its own pull request and release. Decisions below were settled in the questioning turn; nothing here changes the pacing engine.

## Decisions settled

| Topic | Decision |
|---|---|
| Version format | `0.MAJOR.MINOR.PATCH` (4.1.0 becomes 0.4.1.0). Installed copies are updated by hand once; automatic updates work from the first new-format build. |
| History | CHANGELOG and docs relabelled to the new format, with a mapping note at the top. Old GitHub tags and releases stay as they are. |
| Redesign (#1) and simplification (#2) | Documented in `docs/PLANNED_FEATURES.md` only. No redesign work in this effort. |
| String audit (#4) | Markdown inventory in `docs/`, grouped by screen, with a blank proposal column. |
| Hero pages (#5.2) | The hero shows planned pages and homework. Tapping the pages opens the edit; saving taught pages marks the lesson done. |
| Book types (#8.1) | SB, WB, GB, WrB, SkB, R, Supp. Existing books are matched by name where clear; others stay Unclassified and keep today's initials until the teacher picks a type. |
| Menu and switcher (#5.7, #5.8) | Designer's defaults: Share & print, Plan, Lessons, Help in the menu; a switcher sheet from the group name. |
| Delivery | Five PRs, each bumping the version. Order: A, D, B, C, E. |
| Hero look | Full Saffron fill (accent, onAccent); buttons inside stay neutral. |
| Hero edit | Saving taught pages always marks the lesson done, even if identical to the plan. |
| Progress | One-line strip (thin bar plus key figure); details open on tap. |
| Group-home pills | 2x2 grid of equal pills: Plan, Work, Stats, Settings. |
| Switcher | Picking a group always opens that group's home; from nested pages the sheet lists the other three pages. |
| Custom-plan red | Only the differing book's pages turn red; the lesson also gets a TalkBack marker. |
| Group finish date | Shown under the book with a "Class: <date>" note and a "Use class date" action. |
| Removing a default book from a group | Taught history kept, untouched lessons re-paced, hand-edited custom lessons left alone and flagged in warnings. |
| Days off long-press | Edit (pre-filled add sheet) and Delete with Undo; inherited class days off stay read-only. |
| String inventory | Everything seen or heard: strings.xml, TalkBack labels, printed output, engine warnings. |
| Copy changes | None beyond strings new features need, until the owner returns the filled-in inventory. |

## Deliverables

### A. Versioning, roadmap, string inventory (#3, #1, #2, #4)
- `versionName` becomes `0.4.1.x` style; `UpdateModel` version parsing, release validation, tag format (`v0.X.Y.Z`) and asset name (`course-pacer-0.X.Y.Z.apk`) accept four parts. Parsing must still read old three-part tags (a build is never offered an older release). Tests cover both formats and the ordering 0.4.1.0 vs 4.1.0.
- CLAUDE.md rules updated: "always three parts" becomes "always four parts starting 0.", the release contract paragraph names the new tag and asset form, and it states that the first new-format build is installed by hand.
- `release.yml` and `android.yml` version checks updated accordingly.
- CHANGELOG relabelled with a mapping note; docs references updated.
- `PLANNED_FEATURES.md`: new entries for the taste-skill UI/UX audit and redesign (#1) and the streamlining pass (#2, to follow after current feature work).
- `docs/STRING_INVENTORY.md`: every user-visible string from `strings.xml` (702 entries), plus Kotlin-side strings the project keeps out of resources (engine messages, `Nav.problems`, print HTML), grouped by screen, with ID, current text and an empty proposal column.

### B. Group home (#5)
- **Hero colour:** restore a colour fill. `TodayBox` currently uses the neutral `surfaceContainer`; it moves to the accent (Saffron/Bone `accent` and `onAccent`) so it reads as the primary object on every screen that shows it (group home, Plan, anywhere `TodayBox` appears). Contrast pairs are already covered by `ContrastTest`.
- **Hero content:** remove "Pages taught" button. Planned pages and homework (under the pages) stay. Tapping the pages opens the taught-pages edit; saving marks the lesson done and moves on.
- **Progress:** redesigned to the same information in less height (compact strip, not a card stack).
- **Spacing:** one vertical rhythm for the five sections, using `Space` tokens only.
- **Containers:** Progress, Pacing and Work due each sit in a container (`RowGroup`/surface).
- **Pills:** Plan, Work, Stats and Settings as four pill buttons at the foot of group home. Group Settings leaves the three-dots menu.
- **Three-dots menu:** grouped under Share & print (Copy, Share, Print), Plan (My plan actions, Own pace, Adjust catch-up, Term weeks removed, see C), Lessons (Add extra lesson), Help (Tips).
- **Group switcher:** the arrow next to the group name opens a sheet. From group home it lists the other groups. From Plan, Work, Stats or Settings it lists the other three pages.

### C. Group plan (#6)
- In a custom plan, pages that differ from the proposed pages show in the warning (red) colour.
- Toggle labels become "Weekly view" and "Monthly view".
- Weekly view: the term-week pills move under the My plan / Proposed switch; "Term weeks" leaves the menu.
- Monthly view: month navigation moves under the My plan / Proposed switch, with the month text centred between the two arrows.

### D. Books and group settings (#8, #10, #9)
- **Book type** added to `Book` (JSON schema 15, read leniently, old files load with Unclassified). Class book editor gets a type picker. Abbreviations come from the type; the book's name is never used as the abbreviation. `bookInitials`/`shortBookNames` use the type first and fall back to today's logic for Unclassified. Print, Stats, ledger rows and TalkBack short names follow.
- **Remove a book from one group:** default books can be unselected per group (today only optional books toggle). Implemented through the existing group book-membership override so class data is untouched, with a guard that a group keeps at least one book and Undo.
- **Per-group book finish date:** long-press a book in group settings, set a finish-by date for that group only (the class norm stays the default, with a clear way back to it). Uses the existing group end/override path; the engine's per-book `bookLessons` rule is unchanged.
- **Days off in a group:** long-press a day off to edit (label, dates) or delete, with Undo.
- **Main Settings:** remove the "You" label above the name box.

### E. Spacing coherence (#7)
- School year settings screen and the other list screens move to one section rhythm (`Space` tokens in `Rows.kt`: `SectionHead`, `RowGroup`, `FootActions`), so spacing stops differing screen to screen. Audit every screen for stray fixed paddings and fix the worst offenders; B owns group home.

## Order and release
A, then D, then B and C (same files, sequential), then E. Each PR bumps the version (starting `0.4.2.0`), updates CHANGELOG and docs, and passes `testDebugUnitTest`, `assembleRelease`, `lint`. Unit tests are added for: version parsing both formats, book-type abbreviations and migration, group book removal and finish date, hero done-on-edit rule (plain Kotlin model), switcher contents.

## Risks
- Version switch: an installed 4.x will not be offered 0.x builds. Mitigated by the one-time manual install (settled).
- Schema 15 and group book removal touch pacing inputs. Parity guard: with no overrides and Unclassified books, output is byte-identical (existing parity tests remain green).
- Large UI changes cannot be exercised on a device in this environment; layout is verified by compile, unit tests and lint only, so the owner should check each APK on a phone.
